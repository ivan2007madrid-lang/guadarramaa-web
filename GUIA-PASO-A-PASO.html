1. Qué contiene la carpeta

Carpeta o archivoPara qué sirve
dist/La web ya terminada. Es lo que se publica.
content/Todos los textos y datos (rutas, fechas, galería, contacto…). Es lo que cambias.
src/Diseño, imágenes y panel de edición. No hace falta tocarla.
build.jsConvierte content/ en la web. Netlify lo ejecuta solo.
netlify.tomlInstrucciones para Netlify. No hace falta tocarlo.

2. Publicar la web gratis con panel de edición (recomendado)

Con este método editas la web desde un panel con formularios, sin tocar código. Y cada cambio publica la web automáticamente. Necesitas dos cuentas gratuitas: GitHub y Netlify. Tarda unos 20 minutos.

Las pantallas de Netlify y GitHub cambian con el tiempo. Si un nombre de menú no coincide, busca el más parecido. Todos los pasos son gratuitos.

Paso 1. Crear la cuenta de GitHub y subir los archivos

  1. Entra en github.com/signup y crea una cuenta gratuita.
  2. Pulsa New repository (nuevo repositorio). Ponle un nombre, por ejemplo guadarramaa-web. Déjalo en Private (privado).
  3. Pulsa uploading an existing file y arrastra todo el contenido de la carpeta de la web (content, src, dist, build.js, netlify.toml, package.json). Pulsa Commit changes.
  4. Apunta tu usuario/repositorio, por ejemplo maria/guadarramaa-web.

Paso 2. Indicar tu repositorio al panel

  1. En GitHub abre src/admin/config.yml y pulsa el lápiz para editarlo.
  2. Cambia la línea repo: TU-USUARIO/TU-REPOSITORIO por la tuya, por ejemplo repo: maria/guadarramaa-web. Pulsa Commit changes.

Paso 3. Publicar en Netlify

  1. Entra en app.netlify.com/signup y regístrate con tu cuenta de GitHub (plan gratuito).
  2. Pulsa Add new site → Import an existing project → GitHub y elige tu repositorio.
  3. Netlify detecta solo la configuración (node build.js y carpeta dist). Pulsa Deploy.
  4. En un minuto tendrás una dirección tipo https://nombre-aleatorio.netlify.app.
  5. Para cambiar el nombre: Site configuration → Change site name. Por ejemplo guadarramaa-guidess, que daría guadarramaa-guidess.netlify.app si está libre.

Paso 4. Activar el acceso al panel (una sola vez)

  1. En GitHub: Settings (tu perfil) → Developer settings → OAuth Apps → New OAuth App.
  2. Rellena: nombre libre; Homepage URL = la dirección de tu web; Authorization callback URL = https://api.netlify.com/auth/done. Pulsa Register application.
  3. Pulsa Generate a new client secret. Copia el Client ID y el Client secret.
  4. En Netlify: Site configuration → Access & security → OAuth → Install provider. Elige GitHub y pega los dos datos.
  5. Abre tu-direccion.netlify.app/admin/, pulsa Login with GitHub y ya puedes editar.

Paso 5. Poner la dirección de la web

En el panel, entra en Textos de la web → Datos de contacto y ajustes y escribe la dirección completa en Dirección de la web. Con eso se activan el mapa del sitio y los enlaces canónicos para Google. (Si no lo haces, Netlify la rellena sola al compilar, pero conviene escribirla.)

3. Alternativa rápida: arrastrar y soltar

Sirve para ver la web publicada en dos minutos, pero sin panel de edición.

  1. Entra en app.netlify.com/drop.
  2. Arrastra la carpeta dist entera.
  3. Netlify te da una dirección .netlify.app.
Con este método, para cambiar un texto hay que regenerar la carpeta dist con Node.js y volver a subirla. Por eso recomendamos el método de la sección 2. Además, sin la dirección web configurada no se genera el mapa del sitio para Google.

4. Cómo actualizar cada cosa

Entra en tu-direccion.netlify.app/admin/. Cada vez que pulsas Publish (Publicar), la web se actualiza sola en un par de minutos.

Añadir una ruta nueva

  1. Rutas guiadas → Nueva ruta.
  2. Escribe el nombre y rellena los datos reales: duración, distancia, dificultad, desnivel, punto de encuentro, material, precio y descripción. Lo que dejes vacío se muestra como «Por confirmar».
  3. Sube la foto principal y las demás fotos.
  4. Pulsa Publish. La ruta aparece en la página de rutas, en el menú, en la portada y en el formulario de reservas, con su propia página.

Para ocultar una ruta sin borrarla, quita la marca Publicada.

Cambiar fotografías

  • Portada: Textos de la web → Portada → Foto de portada.
  • Una ruta: Rutas guiadas → elige la ruta → Foto principal y Más fotografías.
  • Galería: Galería de fotos → Fotografías → añade o cambia fotos. Puedes asociar cada foto a una ruta para que salga al filtrar.
Consejo: antes de subir una foto, reduce su tamaño en squoosh.app (gratis). Una foto de unos 1600 píxeles de ancho y menos de 400 KB hace que la web cargue rápido. Escribe siempre una descripción corta en la foto de la galería: ayuda a Google y a las personas con lector de pantalla.

Modificar precios

Rutas guiadas → la ruta → campo Precio. Escribe exactamente lo que quieres mostrar, por ejemplo «25 € por persona».

Añadir fechas y actividades

Fechas y actividades → Próximas salidas → Add salidas. Elige la ruta, la fecha, la hora y las plazas. Si es otra actividad que no es una ruta, deja la ruta vacía y escribe su nombre. Las fechas pasadas se ocultan solas.

Publicar noticias y artículos

Blog y novedades → Nuevo artículo. Escribe título, fecha, resumen, imagen y texto. Marca Borrador si aún no quieres publicarlo.

Cambiar textos y datos de contacto

  • WhatsApp, correo, teléfono, Instagram: Textos de la web → Datos de contacto y ajustes.
  • Portada, servicios, quiénes somos, preguntas frecuentes, opiniones, aviso legal: cada uno tiene su apartado en Textos de la web.

Si no quieres usar el panel

Puedes editar los archivos de la carpeta content directamente en GitHub (abre el archivo, pulsa el lápiz, cambia el texto entre comillas y pulsa Commit changes). Netlify publica el cambio solo. Respeta las comillas y las comas.

5. Los textos «PROVISIONAL»

Todo lo que no me dijiste está escrito como texto provisional con fondo amarillo. En los archivos y en el panel empiezan por PROVISIONAL:. Para sustituirlo, borra esa palabra y escribe tu texto. Los datos vacíos se ven como «Por confirmar».

Cuando todo esté completo, en Datos de contacto y ajustes quita la marca Mostrar aviso de prototipo para ocultar la barra superior.

6. WhatsApp y correo

En Datos de contacto y ajustes escribe el número de WhatsApp con prefijo y sin espacios ni signos. Ejemplo: 34600123456. Si escribes solo 9 cifras españolas, la web añade el 34. Desde ese momento todos los botones de WhatsApp abren la conversación con un mensaje ya escrito, que menciona la ruta si el botón está en su ficha. Mientras esté vacío, los botones llevan al formulario de contacto.

Comunidad de WhatsApp (voluntaria)

La web ya tiene preparada la sección. Hasta que tengas el enlace, el botón Unirme a la comunidad aparece desactivado y marcado como pendiente. Nadie se añade automáticamente: cada persona entra pulsando el enlace.

  1. Crea la comunidad en WhatsApp y copia su enlace de invitación.
  2. En el panel: Textos de la web → Datos de contacto y ajustes → Enlace de invitación a la comunidad de WhatsApp, pega el enlace y publica.

La web solo acepta enlaces que empiecen por https://chat.whatsapp.com/ o https://whatsapp.com/channel/.

Instagram

El enlace se crea a partir del usuario @Guadarramaa.guidees y está pendiente de confirmar. Cuando compruebes que abre tu perfil, pega la dirección completa en Enlace completo de Instagram y desaparecerá el aviso. Revisa también la ortografía del usuario.

7. El formulario de contacto

Sí necesita un servicio, y ya está preparado: usa Netlify Forms, incluido en tu cuenta de Netlify, sin programar. Netlify guarda cada mensaje y puedes recibir un aviso por correo.

  1. Publica la web y envía un mensaje de prueba desde la página de contacto.
  2. En Netlify: Forms → verás el formulario contacto y los mensajes.
  3. Para recibir un correo con cada mensaje: Forms → Form notifications → Add notification → Email notification.

El plan gratuito incluye un número limitado de envíos al mes. Consulta el límite actual en la página de precios de Netlify. Las reservas más urgentes siguen yendo por WhatsApp. Alternativas gratuitas si algún día lo necesitas: Formspree o Web3Forms.

8. Aparecer en Google

Ya está hecho: títulos y descripciones propios en cada página, una página por ruta, textos con «rutas guiadas Sierra de Guadarrama», «senderismo guiado» y «excursiones guiadas», datos estructurados, mapa del sitio, etiquetas para compartir en redes, web rápida y accesible.

Lo que depende de ti y marca la diferencia:

  1. Alta gratuita en Google Search Console. Añade tu dirección y envía /sitemap.xml.
  2. Crea tu ficha gratuita en Google Business Profile si encaja con tu actividad.
  3. Sustituye las ilustraciones por fotos reales y escribe descripciones propias y detalladas de cada ruta. Google premia el contenido original.
  4. Publica artículos en el blog con regularidad.
  5. Pide a tus clientes opiniones reales y, con su permiso, publícalas.

Nadie puede garantizar una posición en Google. El SEO tarda semanas en dar resultados.

9. Costes y límites

  • Coste: 0 €. GitHub, Netlify (plan gratuito), el panel de edición y el formulario no cuestan nada. La dirección será algo.netlify.app.
  • Los planes gratuitos tienen límites de uso (ancho de banda, envíos de formulario) que Netlify puede modificar. Para una web de este tamaño suelen sobrar.
  • Las tipografías se cargan desde Google Fonts. Si quieres evitarlo por privacidad, se pueden alojar en la propia web.
  • El mapa de OpenStreetMap solo se carga cuando la persona pulsa el botón.
  • La web no usa cookies ni analítica, así que no necesita banner de cookies. Si añades Google Analytics u otros servicios, sí lo necesitaría.
  • Netlify Forms, Netlify y GitHub son servicios de terceros. Revisa sus condiciones actuales.

10. Lo que falta por poner

  • Fotografías reales de la Sierra de Guadarrama. Las actuales son ilustraciones provisionales. Usa solo fotos tuyas o con licencia que lo permita.
  • Datos reales de las rutas de El Escorial y del Valle de la Fuenfría.
  • Número de WhatsApp, correo y teléfono.
  • Textos de la empresa, equipo, titulaciones, seguros y servicios.
  • Fechas de las salidas.
  • Opiniones reales de clientes (la sección muestra huecos marcados hasta entonces).
  • Seguros y requisitos legales: revisa con un profesional los seguros y los requisitos legales de la actividad antes de comercializar las salidas. La web no afirma que exista ningún seguro ni acreditación distinta de las que indicaste. Consulta PENDIENTE-DE-REVISAR.md.
  • Aviso legal y política de privacidad reales, con tus datos de titular. Los textos incluidos son un esqueleto, no asesoramiento legal.
